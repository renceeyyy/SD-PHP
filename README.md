# SD-PHP

Requirements na need

1. Download and Install any local web server such as XAMPP.
   
2. Download the provided source code zip file.
Setup/Installation

3. Open your XAMPP/WAMP's Control Panel and start the "Apache" and "MySQL".
   
4. Extract the source code zip file.
   
5. If you are using XAMPP, copy the extracted source code folder and paste it into the XAMPP's "htdocs" directory.
   Browse the PHPMyAdmin in a browser. i.e. http://localhost/phpmyadmin
   
6. Create a new database naming "lms19".
   
7. Import the SQL file included in the source code folder to your newly created database. The SQL file is known as "lms19.sql".
   
8. Browse the Web Application in a browser. i.e. http://localhost/LabManagement
